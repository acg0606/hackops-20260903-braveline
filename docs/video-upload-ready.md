## Description

Rehearse a difficult workplace conversation in English with BraveLine: prepare a boundary, hear Quiet Coach, record with the guide at zero, and retry one focused phrase after explicitly replacing the previous take.

This demo uses real Android API 36 emulator screen recordings, edited for brevity with English captions. The test emulator had microphone privacy enabled, so the take is silent. The video demonstrates implemented UI behavior, not speech quality. BraveLine does not upload rehearsal audio, transcribe it, or score accent, emotion, or pronunciation.

RevenueCat Test Store is shown with a freshly verified restore. Test Store purchases are simulated: no real charge or revenue. Additional Plus scenarios, counterpart profiles, and rehearsal history are planned, not available functionality in this MVP.
